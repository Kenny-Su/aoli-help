连接公司内网

开始前

请确认电脑可以上网，并准备好以 @hw-etech.com.cn 结尾的公司邮箱。

首次连接

  1. 下载并安装 Tailscale Windows 版，安装完成后打开。
  2. 按下 Windows 键，搜索并打开 Windows PowerShell。复制下面这行命令，粘贴后按回车： 
    tailscale login --login-server=https://headscale.ao-li.com
  3. 按住 Ctrl，点击 PowerShell 中显示的登录链接。如果打不开，就把完整链接复制到浏览器地址栏，按回车打开。在 auth.ao-li.com 页面输入公司邮箱，按提示登录。
  4. 确认页面上的设备和邮箱都是自己的，再点击 Confirm registration（确认注册）。
  5. 看到 Node registered（设备已注册），就可以关闭这个页面了。
  6. 回到 Tailscale。如果还没连接，点击 Connect（连接），直到显示 Connected（已连接）。

确认是否连通

在 PowerShell 中输入下面这行命令，按回车：

tailscale ping 100.64.0.1

看到 pong 回复，就说明已经连上服务器了。

下次使用

打开 Tailscale，在账号菜单中选择自己的公司邮箱。如果还没连接，点击 Connect（连接）。使用公司系统时，请保持 Tailscale 连接。

常见问题

  • 提示找不到命令：确认已安装并打开 Tailscale，再关掉 PowerShell，重新打开试试。
  • 登录页面不对：重新复制上面的完整登录命令，粘贴到 PowerShell 后按回车。
  • 登录失败：确认填写的是公司邮箱，并按页面提示完成邮箱验证。
  • 连接测试没有回复：确认电脑可以上网、登录的是公司邮箱，且 Tailscale 显示已连接。
  • 还是无法使用：把报错截图和打不开的系统地址发给 IT。
