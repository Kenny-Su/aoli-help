连接公司内网

完成一次设置，之后每次打开 Tailscale，就能连接公司网络。

Windows首次设置 · 6 个步骤

开始前，准备好你的公司邮箱。请使用以 @hw-etech.com.cn 或 @snet-sh.com 结尾的邮箱登录。

首次连接

  1. 安装 Tailscale

    下载 Windows 版 Tailscale，安装完成后打开。

    下载 Tailscale ↗

  2. 运行连接命令

    按下 Windows 键，搜索并打开 Windows PowerShell。复制下面这行命令，粘贴后按回车。

    Windows PowerShell
    tailscale login --login-server=https://headscale.ao-li.com
    查看操作截图

  3. 使用公司邮箱登录

    按住 Ctrl，点击 PowerShell 中显示的登录链接。如果打不开，就把完整链接复制到浏览器地址栏，按回车打开。

    在 auth.ao-li.com 页面输入以 @hw-etech.com.cn 或 @snet-sh.com 结尾的公司邮箱，按提示登录。

    查看操作截图

  4. 确认设备注册

    确认页面上的设备和邮箱都是自己的，再点击 Confirm registration（确认注册）。

    查看操作截图

  5. 完成注册

    看到 Node registered（设备已注册），就可以关闭这个页面了。

    查看操作截图

  6. 确认连接成功

    回到 Tailscale。如果还没连接，点击 Connect（连接），直到显示 Connected（已连接）。

下次使用

打开 Tailscale 即可。使用公司系统时，请保持 Tailscale 连接。

连接成功后，请稍等片刻再访问公司系统。如果暂时打不开，请稍后刷新页面重试。
